# 数据权限（DataFilter）三分钟讲解版

> 来源：中小厂面经里"数据隔离/数据权限怎么做的"是**明确出现过**的追问（浩鲸科技一面为此连问 9 题）。
> 本项目已有完整实现（P1-8，批次22），本档只是把它压成"3 分钟能讲完 + 每句都有代码位置"的版本。
> 代码位置：`admin/annotation/DataFilter.java`、`admin/aspect/DataFilterAspect.java`、`admin/data/DataScopeSupport.java`、
> `admin/security/AdminContext.java`；剧本证据：`scripts/verify/batch22/_c27_data_scope.ps1`（24/24 PASS）。

## 1. 问题（20 秒）

管理端有 4 个角色（SUPER/OPS/FINANCE/SUPPORT）与 37 个权限码。**权限码管"能不能做这件事"，
管不了"能看到哪些数据"**：一个站点管理员有"查工单"的权限，但不应看到别的站点的工单。
这一层叫数据范围（row-level scope）。

## 2. 我的模型（30 秒）

两层，缺一不可：

| 层 | 机制 | 失败时的表现 |
|---|---|---|
| 角色权限（功能级） | `@PreAuthorize("hasAuthority('admin:work-order:read')")` → 403 | 用户点不动/看不到入口 |
| 数据范围（行级） | 登录时解析出 `dataScope=ALL \| STATION` + 可见站点集 `scopeStationIds[]`，**每次查询按它加条件** | 查询结果为空（fail-closed），或越域资源 403 |

数据范围**只在登录时解析一次**，放进 `AdminContext`（请求级 ThreadLocal），后续查询直接读——
不每次查库解析权限，也不把范围交给前端。

## 3. 三个关键设计选择（60 秒，这是能追问的部分）

**① 过滤条件在查询构建处，不在注解里**
`@DataFilter("order-list")` **不是** SQL 注入器（那是 MyBatis-Plus 多租户插件的做法，
它要改 SQL 解析器、且对自研查询不透明）。注解只做一件事：**空转自检**——
切面在方法返回后检查"这次查询到底有没有真的调用过范围工具"，
调用了才放行；没调用就在日志/测试里报"声明了数据范围却没生效"。
真实过滤由查询处显式调用 `DataScopeSupport.applyStation(wrapper, ...)` / `requireStationAccess(id)`。

> 为什么这么设计：让"忘记加过滤"从**静默越权**变成**显式报错**。
> 这是本项目的通用纪律：能用结构约束表达的，就不要靠记性（同一个思路见能力位 `ActionsSupport`
> 与事务自调用守卫 `TransactionalSelfInvocationGuardTest`）。

**② fail-closed：拿不到范围就返回空集**
`DataScopeSupport` 在"受限身份但可见站点集为空"时，往 wrapper 里塞**恒假条件**（`IN ()` 的等价物），
而不是"不加条件"。区别是致命的：不加条件 = 全量越权可见。
受限身份若连"我是哪个站的"都解析不出来（配置脏/账号没绑站），宁可让他什么都看不到，也不能放开。

**③ 无归属资源要显式声明，不能默认放行也不能假装过滤**
不是所有表都有站点归属列：结算单是**代理商维度**、渠道对账是**渠道维度**、调拨是**跨站任务**。
对这些资源本项目**显式声明为"全局口径"**并在代码/文档写明，而不是塞一个恒真的假过滤装样子。
只有确实有归属却漏过滤的才是缺陷——`work_order` 就是这种：它只有 `device_no`，
批次29 通过 `device_no → 柜 → 站` 解析出 `station_id`（db/17 补列 + 回填）后才真正受控。

## 4. 覆盖与验证（30 秒）

- 六类列表（站点/柜/仓/电池/订单/看板）与资源级详情、创建越域全部接入；
- 看板特殊处理：受限身份**不共享全局缓存**，按本域直算（否则会读到全量口径的缓存值）；
- BFF 聚合层内部每个子查询各自走范围工具——**聚合不能成为越权旁路**（这是 S8 加视图层时特意加的纪律）；
- 剧本 `_c27` 24/24：站点范围账号只看到本域列表、越域详情 403、拒绝请求无副作用、
  跨域创建 403、无归属资源 fail-closed。

## 5. 一句话收尾

"权限码管**动作**，数据范围管**行**；数据范围在**登录时解析、查询处执行、注解只做自检**；
拿不到范围就 **fail-closed 空集**；没有归属列的资源**显式声明为全局口径**，不做假动作。"
