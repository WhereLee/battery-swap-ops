# 视觉复核通道（用视觉模型给界面做二次复核）

> 建立：批次38（2026-09-19）｜ 定位：**疑点生成器**，不是判定者
> 适用场景：改了前端界面之后，想知道"人眼看上去有没有问题"；或截图要给面试官看之前做一次体检

## 一、为什么需要它，以及它的边界

界面正确性在批次31 已有两层证据：`_c34`（HTTP 契约）与 `_c35`（能否渲染）。两者都**看不见**
"文字是否读得出来""区块是否空白"。而"截图"这一交付物在此之前**完全没有判据**。
视觉模型补的正是这一环——但它只能**提出疑点**，判定必须回落到 DOM 测量。

| 它擅长的 | 它不可信的 |
|---|---|
| 页面结构、页签名、行数区间、表头文字 | 一切**数字**（对比度、像素、列宽） |
| 看出"某块是空的""某列没东西""看起来歪了" | 12px 小字（读不出时会说成"没渲染"） |
| 复述页面上的中文标签 | 相邻列串读、把 `fixed` 列在截图里的粘滞错位当成布局错位 |

实证数据与逐条模式见 `document/pitfalls/vision-review-false-positive-patterns.md`。

## 二、怎么调（本机可复现）

模型：`deepseek-v4-flash-vision-exp`（`input: [text, image]`），provider `opencode-go`。
调用方式：DSH 的 workflow 工具，脚本里给 `agent()` 指定 provider/model 覆盖。

```
workflow({
  meta: { name: "ui-visual-review", description: "..." },
  script: `
    const path = 'C:\\\\...\\\\.local\\\\b31-shots\\\\06-orders.png';
    const text = await agent(
      'Open this image with the read_image tool (exact absolute path):\\n' + path +
      '\\nIt is a full-page screenshot of a Chinese admin console. ' +
      'List every Chinese word you can read inside a coloured tag. ' +
      'If you cannot read a tag, say ILLEGIBLE. Do not guess.',   // ← 不要给 schema
      { label: 'orders', provider: 'opencode-go', model: 'deepseek-v4-flash-vision-exp' },
    );
    return text;
  `,
})
```

要点（都是踩过的坑）：

1. **绝对路径写在 prompt 里**，模型自己用 `read_image` 打开；不要试图把图塞进 prompt。
2. **不要给 `schema`**：该模型不产出可被 schema 校验的结构体，强制 schema 会让**每个 agent 返回 null**
   （实测 11/11 失败；去掉 schema 后 11/11 成功）。让它按"最多 N 行纯文本"的格式答，自己在脚本里解析。
3. **一图一 agent**，并在 prompt 里限定输出行数，控制上下文成本（11 张图 ≈ 11 个短回答）。
4. **把已知的 DOM 事实写进 prompt**（视口尺寸、零溢出、零裁切、对比度区间），
   否则它会重复汇报这些已经测过的项，还会与你已知的事实打架。
5. 明确告诉它：**"如果只是你 OCR 不出来，就不要报"**——显著减少假阳性。

## 四、一轮完整复核的流程（批次38 实际做法）

1. `_c35` 重新出图 → 视觉模型逐张读，产出"疑点清单"；
2. **每条疑点翻译成一个可测量的量**，写进 `_c38_ui_probe.mjs`（本次因此新增"表头/表体是否错列"
   "表头文字是否截断""整列是否有可见文字"三条判据——它们此前**无法被证伪**）；
3. 跑 `_c38`，用数字结案：真缺陷 → 修 → 复测；假阳性 → 记入 pitfall 文档，避免下一轮重复争论；
4. 复测后**再让视觉模型看一遍**，确认修复在人眼里也成立（本次确认了"进度条 + 100%"、
   "守恒校验块文字可读"，它同时**撤回了**自己上一轮"表头错位"的说法）。

## 五、成本与取舍

- 该通道**不进 CI**：需要外部模型凭据，且输出不确定。CI 里的判据只有 DOM 测量（确定、可复现、零依赖）。
- 每轮复核成本 ≈ 11 次读图调用；只在"界面有改动"时跑，不必每次 push 都跑。
- 结论落档位置：批次记录（结论）+ `document/pitfalls/`（偏差模式）+ `_c38_out.txt`（机器证据）。
