## 实现

- **pom**：`micrometer-registry-prometheus`（版本由 Spring Boot BOM 管理）。
- **application.yml**：`management.endpoints.web.exposure.include: health,info,prometheus`；`show-details: never`。
- **AdminSecurityConfig**：`securityMatcher("/admin/**", "/actuator/**")`；health/info 放行，其余需 `X-Admin-Token`
  （break-glass 静态 token 或会话 token）；设备/用户/dev 路径不经此链（零影响）。
- **SwapMetrics**（`common/metrics`）：Gauge 供应商式注册——Prometheus 抓取时求值；
  覆盖 outbox 积压/死信、未处理告警、延迟任务积压（按 topic）、最近对账差异、可分配满电仓总量。
- **单测 2 例**：注册齐全 + 供应商取值；求值异常降级 -1。

## 诚实边界

- 本机无 Grafana/Prometheus 运行环境（无 Docker）：面板以"可导入 JSON + 抓取实据（61KB body、6 指标逐项命中、401/200 鉴权对照）"交付，未截真实面板图。
- 指标中的表计数为 `SELECT COUNT` 直查（单机/演示口径，10 柜小基数）；大基数场景应改为缓存或预聚合——已在代码注释标注边界。
- 抓取频率建议 15s；`swap_alloc_available` 每次求值遍历全部可用柜做 SCARD（10 柜量级开销可忽略）。
