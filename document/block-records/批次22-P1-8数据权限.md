## 设计要点（与参照实现的差异）

参照 `inteink-faster` 的 `DataFilterAspect` 是"切面拼 SQL 片段（sqlFilter）注入 QueryWrapper.apply"；本项目适配
MyBatis-Plus 后改为**类型安全的条件注入**：

- **不拼 SQL 串**：`DataScopeSupport.applyStation/applyIds` 接收 `LambdaQueryWrapper` + 列引用，调用 `.in()`/`.eq()`——
  零注入面（无字符串拼接，无用户可控输入）；
- **切面只做旁路自检**：真正过滤在查询构建处；`@DataFilter` + 切面负责"防未来新增查询漏接"（受限身份 apply 未发生 → warn），
  非受限身份不告警（`exitAndCheck` 咨询 `AdminContext`，避免 bootstrap/ALL 全量误报）；
- **两级解析**：仓/电池无站点列，走 `站点范围 → 柜 id 集 → 仓 id 集`（`cabinetIdsOrNull`/`cellIdsOrNull`），
  再 `applyIds(cell.cabinet_id / battery.cell_id)`。

## 语义矩阵（终版）

| 身份 | 列表 | 详情/运维 | 创建 |
|---|---|---|---|
| 无上下文（用户端/调度/单测） | 不过滤 | 放行 | 放行 |
| bootstrap / ALL | 不过滤 | 放行 | 放行 |
| STATION{非空集} | 仅域内（IN） | 域内放行 / 越域 403 | 域内有归属放行 / 越域 403 |
| STATION{空集} | 恒假（无行） | 一律 403 | 一律 403（无归属操作亦 403） |

## 诚实边界

- 数据范围覆盖**资产域（站/柜/仓/电池）+ 订单 + 看板**（roadmap 交付口径）；告警/工单/资金/结算等运营域未按站点隔离——
  这些域要么无站点维度、要么为总部角色使用（FINANCE/SUPPORT 默认 ALL），如需按站隔离需在对应查询处补 apply（框架已就绪，一处一行）。
- 站点范围是**登录期快照**（会话期内改配置需重新登录生效；管理员改自己范围=下次登录生效）——与"停用即时生效"的差异已知，可后置刷新机制。
- 看板受限口径为"域内电池按 `battery.cell_id ∈ 本域仓` 计"；在途电池（cell_id 为空）不计入任何站点口径（全局口径同逻辑）。
- 未做行级"创建者"维度、未做数据范围的可视化配置界面（API-only）。
- 本批改动集中在 swap-server + db + scripts + document，无云上动作；本地 371/371 + `_c27` 24/24 + `_c24` 回归 9/9。
