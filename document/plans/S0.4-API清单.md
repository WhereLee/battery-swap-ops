# S0.4 API 清单（battery-swap-ops）

> 阶段：S0 设计冻结 · 第 4 小阶段 ｜ 状态：待自查
> 三段鉴权：设备通道 HMAC（S0.3）/ 用户端 token / 管理端 token（P0 简化，RBAC 见备注）。
> 统一响应：`{code,msg,data}`（错误语义沿用范例：401 未认证 / 400 协议或业务拒绝 / 429 限流 / 5xx 系统）。
> 日期：2026-09-11

## 1. 设备端（柜 → 平台 / 平台 → 柜）

| 方法 | 路径 | 方向 | 说明 |
|---|---|---|---|
| POST | `/api/device/heartbeat` | 柜→平台 | 心跳（判活 TTL） |
| POST | `/api/device/event` | 柜→平台 | 事件上报（序守卫） |
| POST | `/cmd` | 平台→柜 | 开仓指令（同步回执；S0.3 §2.3） |
| POST | `/cmd/query` | 平台→柜 | 实况查询（S3 对账） |

（报文与签名见 `S0.3-设备协议v1.md`。）

## 2. 用户端（小程序/H5 语义先用 API 表达；前端 P0 不做）

| # | 方法 | 路径 | 说明 | 关键请求/响应 |
|---|---|---|---|---|
| U1 | POST | `/api/user/order` | 创建换电订单 | req：`{type: SWAP/TAKE/RETURN, cabinetNo?, stationNo?}`；resp：`{orderNo, cellNo, cabinetNo, batteryNo, expireAt}` |
| U2 | GET | `/api/user/order/{orderNo}` | 订单状态查询 | resp：`{status, feeFen, payType, ...}` |
| U3 | POST | `/api/user/order/{orderNo}/cancel` | 取消（仅未开仓） | 幂等；释放预占 |
| U4 | GET | `/api/user/stations` | 站点列表（含可换电池数） | resp：`[{stationNo,name,cellFullCount,distance?}]` |
| U5 | GET | `/api/user/wallet` | 钱包/套餐摘要 | resp：`{balanceFen, depositFen, activePlan:{...}}` |
| U6 | GET | `/api/user/plans` | 套餐列表 | resp：`[{planId,name,type,priceFen,...}]` |
| U7 | POST | `/api/user/plans/{planId}/purchase` | 购买套餐（模拟支付） | resp：`{userPlanId, payTradeNo}` |

> U1 的分配与预占语义见 S0.1 §6.1；`expireAt` = 预占超时（默认 120s，可配）。

| # | 方法 | 路径 | 说明 |
|---|---|---|---|
| A1 | CRUD | `/api/admin/station` | 站点管理（增删改查/停启用） |
| A2 | CRUD | `/api/admin/cabinet` | 柜管理（登记含密钥导入、启停/维护） |
| A3 | GET | `/api/admin/cabinet/{cabinetNo}/state` | 柜实况（仓/电池快照 + 在线态） |
| A4 | GET | `/api/admin/cell` | 仓列表（按柜/状态过滤） |

## 4. 通用约定

| 项 | 约定 |
|---|---|
| 幂等 | 下单：客户端 `Idempotency-Key` 头（同 key 返回同单）；取消：订单终态幂等；告警处理：CAS |
| 分页 | `page/limit`（沿用范例 PageParams 钳制语义） |
| 时间 | 毫秒时间戳（沿用范例毫秒化） |
| traceId | `X-Trace-Id` 入站 → MDC → 日志；设备指令/事件沿用 |
| 限流 | 设备上行入口限流（per-device + 全局水位），沿用范例 |
| 错误码 | 0 成功；业务失败 1（msg 说明）；401/400/429 语义化（不吞成 200） |

## 5. 与参考的取舍

| 设计点 | 参考 | 取舍 |
|---|---|---|
| 设备接口形态 | OCPP Request/Response + uniqueId 幂等 | **采用** commandSeq 幂等语义；不用 WebSocket |
| 设备认证 | JetLinks HTTP Bearer | **替换**为 per-device HMAC（范例更严） |
| 用户端范围 | orise/100charge 小程序功能（找桩/充电/订单/钱包） | **裁剪**为换电核心（U1-U7），前端不做 |
| 管理端范围 | 100charge 场站/桩/计费/订单 | **裁剪**：不含营销/优惠券/多租户 |
| API 错误语义 | 范例 0.7 语义化分层 | **直接复用** |
